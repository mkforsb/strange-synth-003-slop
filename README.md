# STRANGELET — a very strange synth

Rust + [Dioxus](https://dioxuslabs.com) web app. All audio is generated by a Rust DSP core compiled to
WebAssembly and run inside a WebAudio `AudioWorklet`; the UI (knobs, presets, keyboard, canvas visuals) is Dioxus.

## Run it

```sh
rustup target add wasm32-unknown-unknown   # plus: cargo install dioxus-cli (0.7)
./build-dsp.sh                             # DSP -> app/assets/dsp.wasm  (re-run after DSP changes)
cd app && dx serve --platform web          # dev server, or:
cd .. && ./build-app.sh                    # release bundle in target/dx/strange-app/release/web/public
```

Click **ENTER THE MACHINE** (browsers need a gesture to start audio). Play with the on-screen keys or
the computer keyboard (`Z S X D C V G B H N J M` lower row, `Q 2 W 3 E R 5 T 6 Y 7 U` upper row, `[` `]` = octave).

## Interaction

| | |
|---|---|
| drag a knob | change value (Ctrl/Alt = fine, wheel = step, double-click = reset) |
| **Shift-click** a knob / filter type | **lock** it: ignored by **RND** and by preset changes |
| **RND** | mutates every unlocked parameter (random walk or full re-roll, within safe ranges) |
| HOLD / AUTO▶ / PANIC | sustain latch / audition note on preset change / kill all voices |

## Architecture

```
dsp/   strange-dsp   no-deps Rust crate: params.rs (59 params), presets.rs (58), voice.rs, engine.rs,
                     filters.rs (Moog ladder + EQ), reverb.rs (Dattorro plate). cdylib -> wasm, rlib -> UI + tests
app/   strange-app   Dioxus UI, audio.rs (AudioContext/worklet/analysers), visuals.rs (canvas), assets/worklet.js
tools/ smoke.py      headless-Chromium smoke test (playwright)
```

### Signal flow

`3x swarm oscillators` (wave morph → warp → feedback/ratio FM → wavefold) → ring mod → logistic-map chaos osc → noise →
amp envelope → **8-mode resonant body** (string/bar/sheet/bell/pipe morph, inharmonicity, strike burst, bow feedback) →
3 formant filters → growl AM → decimate/bitcrush → stutter/erode gates → 8 voices →
**master filter** (Moog ladder LP12/LP24, BP, HP) → **EQ** (low cut, low shelf, mid peak, high shelf, high cut) →
**Dattorro plate reverb** → soft limiter. Pitch has dive envelope, glide, drift, and a sine↔sample&hold wobble LFO
that also modulates the filter.
